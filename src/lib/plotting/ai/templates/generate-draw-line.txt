КАК ЗАДАВАТЬ ОБЪЕКТЫ (предпочтительные способы)
— Множество решений (интервал, луч, объединение) задавай ТОЛЬКО как множество (sets). Его граничные точки — выколотые для строгих неравенств и закрашенные для нестрогих — приложение отметит само, с координатами.
— НЕ добавляй в points точки, совпадающие с границами множеств: они уже есть.
— В points попадают только отдельные точки, которые не являются границами множеств.
— Несколько прямых друг под другом — несколько элементов rows. Каждая прямая имеет свои множества и точки; шкала у всех прямых общая. Ответ на систему неравенств, как правило, изображается отдельной прямой.
— Несколько интервалов на одной прямой: либо несколько элементов sets, либо одно множество типа "set" с записью объединения.
— Строгость границы: строгое неравенство (<, >) — граница выколота (open: true); нестрогое (<=, >=) — закрашена (open: false).

Числа — строки-выражения math.js ("-3", "1/2", "2*pi", "sqrt(2)"). Бесконечность: "inf" и "-inf" (только в записи множеств и как граница интервала; она всегда открыта).

{{MATH_NOTATION_RULES}}
На числовой прямой выражений-формул нет — только числовые значения: пиши ТОЛЬКО само число или выражение, без пояснений и единиц. «x = 3.» → "3".

SET — три вида:
1. Интервал или отрезок:
   { "type": "interval", "from": "3", "to": "4", "fromOpen": true, "toOpen": true }
   fromOpen / toOpen: true — граница выколота (строгое неравенство), false — закрашена. Если опустить, граница считается выколотой.
   Одна из границ может быть "-inf" или "inf" — получится луч.
2. Луч:
   { "type": "ray", "direction": "right", "boundary": "2", "open": false }
   direction: "right" — x > a или x >= a; "left" — x < a или x <= a. open: true для строгого неравенства. Если опустить, граница выколота.
3. Объединение интервалов записью:
   { "type": "set", "notation": "(-inf; -2] ; [1; 3)" }
   Каждый интервал — в скобках, границы внутри скобок разделены «;»; сами интервалы разделены «;» вне скобок. Скобка «(» или «)» — граница выколота, «[» или «]» — закрашена; бесконечность — всегда со скобкой «(» или «)».
Необязательное поле любого множества:
   "side": "above" | "below" — с какой стороны оси штриховка; по умолчанию "above". Меняй, только если на одной прямой нужны два множества, не накладывающиеся друг на друга (например, решения двух неравенств системы).

POINT — отдельная точка на прямой:
   { "x": "2", "label": "A", "open": false }
   "x": координата;
   "label"?: название точки ("A"), берётся из задания;
   "open"?: true — выколотая точка; по умолчанию закрашена;
   "showCoords"?: boolean — показывать координату; по умолчанию: да, если нет label, и нет, если label задан;
   "perpendicular"?: boolean — провести вертикальную пунктирную линию через точку (через все прямые): помогает сопоставить точки на разных прямых.

ПРАВИЛА
— Каждый пункт плана превращай в прямую, множество или точку; ничего не пропускай и ничего не добавляй.
— Прямые перечисляй сверху вниз в том порядке, в каком они идут в плане.
— Если в плане одна прямая — в rows ровно один элемент.
— Не придумывай значения, которых нет в плане; не добавляй цвета и оформление.
— Шаг шкалы ВСЕГДА 1 (его задаёт приложение); никакого поля шага в ответе нет и быть не может. Менять шаг можно только по прямому запросу пользователя.
— Деления и числа на оси (ticks): для чертежей с множествами (интервалы, лучи, неравенства) их НЕТ вообще — не пиши ticks. ticks: "all" допустимо только для чертежа из одних отдельных точек, если план прямо требует числовую шкалу.
