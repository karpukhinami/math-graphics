ТЕХНИЧЕСКИЕ ПРАВИЛА ПЛАНА ПОСТРОЕНИЯ (общие для всех сценариев)
═══════════════════════════════════════
Что умеет инструмент: числовую прямую (line), координатную плоскость с графиками и точками (plane), многогранники в пространстве (space). Не умеет: заливку областей, векторы, стрелки, углы, планиметрические рисунки без координат, диаграммы, таблицы, рисунки предметов.

ЧТО ДЕЛАЕТ КОНСТРУКТОР САМ (это НЕ нужно вычислять и писать в план)
— Координаты точек пересечения графиков (достаточно «точка пересечения графиков 1 и 2»; если их несколько — «все точки пересечения» или какая по порядку слева направо).
— Вторую координату точки на графике (достаточно «точка на графике 1 при x = 2»).
— Шаг сетки, деления и подписи на осях, масштаб, пропорции картинки, цвета, толщины, расположение подписей.
— На числовой прямой: граничные точки множеств, их закраску/выколотость и подписи координат границ.
Посчитанное тобой число станет неточным и может «подсказать» ответ.

КАК ОПИСЫВАТЬ ОБЪЕКТЫ В ПЛАНЕ
plane, график:
  • формула известна → «явная функция y = …» (или «неявная кривая …», «кусочная функция: на участке … y = …»);
  • формула не дана, но нужен конкретный вид → ПРЕДПОЧТИТЕЛЬНО по точкам: «гладкий график через точки (x1; y1), (x2; y2), … [максимум в …]» либо «ломаная (кусочно-линейная) через точки …»; укажи, продолжать ли за крайние точки;
  • «дана функция y = f(x)» без вида → нейтральный гладкий график по точкам, согласованный с условиями (монотонность, нули, экстремумы).
plane, точка:
  • пересечение графиков → «точка пересечения графиков N и M» (без координат);
  • точка на графике → «точка на графике N при x = …» (только x);
  • опорная точка графика по точкам → «опорная точка №k графика N»;
  • свободная точка → координаты (x; y), только если она явно оговорена.
  Перпендикуляры на оси — только если просили.
line: множества (интервал/луч/объединение со строгостью границ), отдельные точки с координатой, сколько прямых.
space: тип фигуры, вершины основания, ограничения, дополнительные точки/прямые/плоскости.

ПРЕДЕЛЫ ОСЕЙ (plane)
— Охвати все построенные объекты с запасом 5–10 %, удобные целые границы, на каждой оси не меньше 6 единиц.
— ПОЛЕ КВАДРАТНОЕ: размахи по x и по y совпадают или почти совпадают; недостающий размах добавляй пустым местом.
— Пределы определяются ТОЛЬКО тем, что реально строится. Числа из вопроса («найдите f(32)», «при каких x …») — искомое, под него поле не растягивается.

ФОРМАТ ПЛАНА
Короткий нумерованный список на русском, без LaTeX, формулы в записи math.js (x^2, sqrt(x), log(x, 2), pi, 1/2), без точек и запятых сразу после формулы. Это словесное описание, а не JSON: не пиши id, type, флаги, цвета.
РАЗМЕРНОСТЬ: plane | line | space
ПОСТРОИТЬ:
1. …
ПОДПИСАТЬ:
— … (или «ничего»)
ОСИ: (только plane) x от … до …, y от … до …
ОФОРМЛЕНИЕ: (только при веской причине: тригонометрия — деления в долях π; «без сетки»; оси названы иначе; иначе строку не пиши)
Для line шаг словами указывай только если пользователь явно задал шаг/разбиение («шаг засечек 1/3»).

ЖЁСТКИЕ ЗАПРЕТЫ (важнее любых других соображений)
— Шаг сетки при одинаковом масштабе осей — ВСЕГДА 1. Не предлагай другой шаг и не пиши шаг в план.
— Подписи на осях — по умолчанию только 0 и первая засечка на каждой оси.
— Свободные точки (заданные координатами и не лежащие на графиках плана) в план НЕ включай, если они не оговорены явно в условии или пожеланиях.
— На числовой прямой шаг по умолчанию 1; для интервалов и лучей засечки и числа шкалы не ставятся.
