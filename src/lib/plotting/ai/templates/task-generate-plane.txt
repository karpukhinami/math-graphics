□ 1. Оси: выписал xMin, xMax, yMin, yMax ровно из строки «ОСИ» плана. Если строки нет — выбери сам: все объекты с запасом 5–10 %, целые удобные границы, размахи по x и y близки (не более 1,5 раза), не менее 6 единиц на оси.

□ 3. Тип каждого графика: формула y = f(x) → explicit; равенство с x и y или вертикальная прямая → implicit; разные формулы на участках → piecewise; «гладкий график через точки» → points + connect "smooth"; «ломаная / кусочно-линейная / отрезок» → points + connect "segments".
□ 4. Тип каждой точки (первое подходящее сверху): пересечение графиков → intersection (без координат!); точка на графике при x = … → onGraph (только x); опорная точка графика по точкам → graphPoint; иначе → coords, но ТОЛЬКО если такая отдельная точка явно оговорена в плане (а план — в условии или пожеланиях).
□ 4а. GRAPH (у каждого "id": "g1", "g2", … — на него ссылаются точки):
  { "id": "g1", "type": "explicit", "expression": "x^2 - 2*x" }
  { "id": "g2", "type": "implicit", "equation": "x^2 + y^2 = 25" }
  { "id": "g3", "type": "piecewise", "pieces": [
      { "expression": "x", "from": "", "to": "0", "includeFrom": false, "includeTo": false },
      { "expression": "x^2", "from": "0", "to": "", "includeFrom": true, "includeTo": false } ] }
      from/to "" — без ограничения; includeFrom/includeTo — входит ли граница (закрашенный/выколотый конец).
  { "id": "g4", "type": "points", "connect": "smooth" | "segments",
    "through": [ { "x": "-2", "y": "1" }, { "x": "0", "y": "3", "extremum": "max" }, { "x": "3", "y": "1" } ],
    "extendEnds"?: true }
      ≥ 2 точки с разными x; extremum "min"|"max" — только для smooth; extendEnds — только если план просит продолжить за крайние точки.
  Необязательно у любого графика:
    "label"?: string                          [по плану] только если план велит подписать график
    "domain"?: { "from": string, "to": string } [по плану] ограничение области определения
