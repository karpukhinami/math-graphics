ЧЕК-ЛИСТ ПЕРЕД ЗАПОЛНЕНИЕМ
═══════════════════════════════════════
□ 1. Сколько прямых в плане → столько элементов rows, сверху вниз в порядке плана.
□ 2. Каждое множество → один SET: отрезок/интервал → interval; x > a, x ≤ a и т. п. → ray; объединение → несколько SET или один "set" с записью.
□ 3. Строгость: <, > → граница выколота (open/fromOpen/toOpen: true); ≤, ≥ → закрашена (false).
□ 4. points — только отдельные точки плана, не совпадающие с границами множеств.
□ 5. Подписи: label — только имена из раздела «ПОДПИСАТЬ». showCoords: true — только если план требует показать координату отдельной точки.
