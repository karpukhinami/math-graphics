ФОРМАТ ОТВЕТА
— Верни ТОЛЬКО один JSON-объект в формате, указанном в задании: без markdown-ограждений, комментариев и текста вне JSON.
— Все строковые значения — в двойных кавычках. Если нужен обратный слеш — удваивай его.
— Используй только поля из схемы задания; не добавляй своих полей и не меняй их имена.
— Каждое поле заполняй значением своего типа: числа и формулы — строками в записи math.js там, где схема требует строку; boolean — true/false без кавычек; перечисления — строго одно из указанных значений.
— Не пиши пояснений, единиц измерения и комментариев внутри значений полей (кроме текстовых подписей); необязательное поле, которое не нужно, просто не указывай; null ставь только там, где схема явно допускает null.
