ЗАПИСЬ ВЫРАЖЕНИЙ — ЖЁСТКИЕ ПРАВИЛА (нарушение ломает построение)
— expression/equation содержат ТОЛЬКО саму формулу: без «y =», без номера формулы, без пояснений.
— В конце выражения НИКОГДА не ставь точку, запятую или другой знак препинания — даже если он есть в тексте задания. «y = 2x^2 - 4x.» → expression: "2x^2 - 4x".
— Десятичные дроби — только через точку (0.5); запятая в десятичных дробях запрещена (запятая — только разделитель аргументов: log(x, 2)).
— Операторы: + - * / ^ и скобки. Неявное умножение допустимо: 3x, 2(x+1). Степень — ^, дробную степень бери в скобки: x^(1/3).
— Константы: pi (или π), e. Пример: "2*pi", "pi/2".
— Корень — sqrt(x) (кубический — cbrt(x)), модуль — abs(x).
— Тригонометрия: sin, cos, tan, asin, acos, atan (аргумент в радианах, всегда в скобках: sin(x), tan(pi/4)).
— Логарифмы: натуральный — log(x) (или ln(x)); десятичный — log10(x); по основанию a — ТОЛЬКО log(x, a): «log_2 x» пиши как "log(x, 2)". Запись log_2 в JSON запрещена.
— Экспонента: exp(x) или e^x.
— Прочее: min(x, 1), max, sign, floor, ceil, round, pow(x, 3).
— Переменные — только имена осей (обычно x и y). Любая другая буква (k, a, t, …) — ошибка; если в задании есть параметр, подставь его числовое значение.
— Обозначения из школьного текста, которых нет в списке, переписывай через поддерживаемые: tg→tan, ctg→1/tan(x), arctg→atan, arcsin→asin, lg→log10, sh→sinh.
— Выражение вне формулы (пределы осей, координаты, шаги) — только числовое выражение без переменных: "-5", "1/2", "2*pi", "sqrt(2)".
— Бесконечные границы: "inf" и "-inf" — только там, где схема это разрешает (числовая прямая).
