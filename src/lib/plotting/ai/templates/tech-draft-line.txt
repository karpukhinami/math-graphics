(Общий блок для всех сценариев. Правила ниже не зависят от того, откуда взят план.)

ЧТО КОНСТРУКТОР ДЕЛАЕТ САМ (не вычисляй и не пиши)
— Граничные точки множеств: ставит их, закрашивает/выкалывает по строгости и подписывает координаты. Не дублируй их в points.
— Диапазон оси (если не задан или не вмещает объекты), шаг и деления шкалы, цвета, штриховку, толщины, номера строк.
— Поле, которое не нужно, просто НЕ пиши: отсутствующее поле = значение по умолчанию (авто).

ПРАВИЛА
— Сколько прямых в плане → столько элементов rows, сверху вниз в порядке плана; одна прямая — ровно один элемент. Шкала у всех прямых общая.
— Каждое множество → один SET: отрезок/интервал → interval; x > a, x ≤ a и т. п. → ray; объединение → несколько SET или один "set" с записью.
— Строгость: <, > → граница выколота (open/fromOpen/toOpen: true); ≤, ≥ → закрашена (false).
— points — только отдельные точки плана, не совпадающие с границами множеств.
— Шаг шкалы по умолчанию 1. axis.step разрешён только по прямому запросу пользователя о шаге/разбиении; сохраняй точную строку, например "1/3". Дробные координаты сами по себе не разрешают менять шаг.
— Деления и числа на оси (ticks): для чертежей с множествами (интервалы, лучи, неравенства) их НЕТ — не пиши ticks. ticks: "all" — только для чертежа из одних отдельных точек, если план прямо требует числовую шкалу.
— axis, ticks, side, perpendicular пиши ТОЛЬКО если план прямо этого требует.

СХЕМА ОДНОГО ЧЕРТЕЖА
[!] — обязательно, [редко] — без веской причины не писать, [по плану] — только если есть в плане.
{
  "axis"?: { "min"?: string, "max"?: string, "name"?: string, "step"?: string },   [редко] step — ТОЛЬКО явно запрошенный шаг; иначе авто = 1
  "ticks"?: "none" | "all",      [редко] авто: none при наличии множеств, all — если только точки
  "rows": [                       [!]
    { "sets": [ SET, … ], "points": [ POINT, … ] }
  ]
}
Числа — строки math.js: "-3", "1/2", "sqrt(2)". Бесконечность — "inf" / "-inf" (граница всегда открыта).

На числовой прямой формул нет — только числовые значения, без пояснений и единиц. «x = 3.» → "3".

SET:
  { "type": "interval", "from": "3", "to": "4", "fromOpen": true, "toOpen": false }
  { "type": "ray", "direction": "right" | "left", "boundary": "2", "open": false }
  { "type": "set", "notation": "(-inf; -2] ; [1; 3)" }   — «(» «)» выколото, «[» «]» закрашено; интервалы разделены «;»
  "side"?: "above" | "below"   [редко] только для двух неналагающихся множеств на одной прямой

POINT:
  { "x": "2" }
  "label"?: string        [по плану] имя точки
  "open"?: true           [по плану] выколотая
  "showCoords"?: boolean  [по плану] показать координату (значение по умолчанию — по правилам подписей выше)
  "perpendicular"?: true  [редко] вертикальная линия через все прямые

ПРИМЕР ОДНОГО ЧЕРТЕЖА (план: прямая 1 — промежуток x ≥ 1; прямая 2 — интервал (-2; 3) и точка A с координатой 0)
{
  "rows": [
    { "sets": [ { "type": "ray", "direction": "right", "boundary": "1", "open": false } ], "points": [] },
    { "sets": [ { "type": "interval", "from": "-2", "to": "3", "fromOpen": true, "toOpen": true } ], "points": [ { "x": "0", "label": "A" } ] }
  ]
}
