КАК ЗАДАВАТЬ ОБЪЕКТЫ (предпочтительные способы)
— Если инструмент умеет получить объект сам, используй это и НЕ вычисляй его координаты вручную:
  · точки пересечения двух графиков → точка типа "intersection" (инструмент находит ВСЕ точки пересечения сам);
  · точка на графике при заданной абсциссе → тип "onGraph" (ординату инструмент вычислит сам);
  · вершина, экстремум или другая опорная точка графика, заданного по точкам → тип "graphPoint";
  · перпендикуляры из точки на оси → флаги dropToXAxis / dropToYAxis (и labelOnAxes для значений на осях).
— Тип "coords" (точка по координатам) используй, только когда точка задана числами в плане и не связана с графиками.
— Отрезок или ломаная — график типа "points" с connect: "segments".
— Кривую без формулы (график по картинке, схематичный график) — график типа "points" с connect: "smooth".
— Вертикальная прямая x = a — график типа "implicit" с equation "x = a".
— Пределы осей: ВСЕ объекты плана (графики по существу, все точки, в том числе найденные точки пересечения) должны попадать внутрь пределов; бери небольшой запас. Если в плане указаны пределы — используй их.

СХЕМА (отвечай строго по ней; необязательные поля помечены «?» и по умолчанию не нужны)
{
  "axes": {
    "xMin": string, "xMax": string, "yMin": string, "yMax": string,
    "xName"?: string,          // только если в задании другое имя горизонтальной оси ("t"); по умолчанию "x"
    "yName"?: string,          // только если в задании другое имя вертикальной оси ("s"); по умолчанию "y"
    "xStep"?: string,          // только если нужен особый шаг ("pi/2"); иначе подберёт приложение
    "yStep"?: string,
    "xLabelFormat"?: "number" | "pi" | "fraction",   // "pi" — подписи в долях π; по умолчанию "number"
    "yLabelFormat"?: "number" | "pi" | "fraction"
  },
  "grid"?: boolean,            // сетка; по умолчанию true, false — только если задание требует чертёж без сетки
  "graphs": [ GRAPH, … ],
  "points": [ POINT, … ]
}

Пределы и числа — строки-выражения math.js ("-5", "2*pi", "1/2"). Выражения: + - * / ^, sin, cos, tan, sqrt, abs, log, exp, pi, e.

GRAPH — один из четырёх видов; у каждого графика есть "id" (любая короткая строка: "g1", "g2", …), на него ссылаются точки:
1. Явная функция:
   { "id": "g1", "type": "explicit", "expression": "x^2 - 2*x" }
   expression — ТОЛЬКО правая часть y = f(x), без «y =».
2. Неявная кривая:
   { "id": "g2", "type": "implicit", "equation": "x^2 + y^2 = 25" }
   Одно равенство с обеими переменными (окружность, гипербола x*y = 1, вертикальная прямая x = 3).
3. Кусочная функция:
   { "id": "g3", "type": "piecewise", "pieces": [
       { "expression": "x", "from": "", "to": "0", "includeFrom": false, "includeTo": false },
       { "expression": "x^2", "from": "0", "to": "", "includeFrom": true, "includeTo": false }
   ] }
   from/to — границы участка по x; пустая строка "" — без ограничения. includeFrom/includeTo — входит ли граница в участок (определяет закрашенный или выколотый конец).
4. График по набору точек:
   { "id": "g4", "type": "points", "connect": "smooth", "through": [ { "x": "-2", "y": "1" }, { "x": "0", "y": "3", "extremum": "max" }, { "x": "3", "y": "1" } ] }
   connect: "smooth" — гладкая кривая, "segments" — ломаная из прямых отрезков (минимум 2 точки, координаты x разные).
   extremum?: "min" | "max" — точка локального экстремума (гладкая кривая проходит её горизонтально).
   extendEnds?: true — продолжить крайние участки до краёв области; по умолчанию график ограничен крайними точками.
Необязательные поля любого графика:
   "label": string — подпись графика (только если задание её требует);
   "domain": { "from": string, "to": string } — ограничить область определения (например, только x >= 0).

POINT — один из четырёх видов:
1. По координатам:       { "type": "coords", "x": "2", "y": "3", "label": "A" }
2. На графике:           { "type": "onGraph", "graph": "g1", "x": "2", "label": "B" }
3. Пересечение графиков: { "type": "intersection", "graphs": ["g1", "g2"] }
   Если найдено несколько точек и им нужны разные подписи — "labels": ["A", "B"] (порядок — вдоль первого графика слева направо; если точек окажется больше подписей, лишние останутся без подписи). Единственная "label" подпишет все найденные точки одинаково.
4. Опорная точка графика по точкам: { "type": "graphPoint", "graph": "g4", "index": 2 }
   index — номер точки в through этого графика, начиная с 1.
Необязательные поля любой точки:
   "label": string        — название точки ("A"); берётся из задания;
   "open": boolean        — true для выколотой точки;
   "showCoords": boolean  — показать координаты рядом с точкой; по умолчанию: да, если нет label, и нет, если label задан;
   "dropToXAxis": boolean — опустить перпендикуляр на ось x;
   "dropToYAxis": boolean — опустить перпендикуляр на ось y;
   "labelOnAxes": boolean — подписать значения на осях в основании перпендикуляров (работает вместе с dropTo…).

ПРАВИЛА
— Каждый пункт плана превращай в график или точку; ничего не пропускай и ничего не добавляй.
— Точку, зависящую от графиков, задавай через её зависимость (intersection / onGraph / graphPoint), а не числами.
— Названия точек и графиков бери из плана и задания.
— Не придумывай значения, которых нет в плане; не добавляй цвета и оформление.
