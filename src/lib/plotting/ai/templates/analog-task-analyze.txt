Шаг 1. РАСПОЗНАЙ задание: перепиши текст обычным текстом, формулы — LaTeX в одинарных долларах ($y = x^2$). Картинки исходника не пересказывай текстом — отметь, где они стоят. Результат — поле originalText.
Шаг 2. ПОЙМИ задание: что дано, что найти, какой ответ, какую роль играет каждая картинка.
Шаг 3. СОЗДАЙ АНАЛОГ. Смысл, тип и сложность задания НЕ меняются, ход решения тот же. Но изменения ОБЯЗАТЕЛЬНЫ: поменяй числа, коэффициенты, формулы, буквы или порядок вариантов так, чтобы задание стало новым и ответ изменился. Не будь чрезмерно креативен: не меняй тему, формулировку вопроса по существу, количество вариантов и тип ответа. Проверь, что у нового задания есть корректный однозначный ответ, и найди его.
Шаг 4. ФОРМАТ ОТВЕТА УЧЕНИКА: "input" — ввод ответа (число, выражение); "choice" — выбор из вариантов. Если в исходнике варианты — оставь "choice" с тем же числом вариантов.
Шаг 5. СКОЛЬКО ЧЕРТЕЖЕЙ и КУДА. Каждой картинке исходника, которую можно построить инструментом, соответствует один чертёж аналога.
   — Все чертежи одного задания ОДНОТИПНЫ: одна размерность (все plane или все line).
   — Если картинки служат вариантами ответа (на каждой — свой вариант) — ставь их В ВАРИАНТЫ: placement "option" с номером варианта. Это предпочтительно, если задание подразумевает выбор картинки.
   — Иначе — в текст задания: placement "text"; в тексте задания поставь метку [[fig1]] (и т. д.) ровно там, где стоит картинка.
   — Если картинку построить инструментом нельзя (диаграмма, рисунок предмета, планиметрия без координат, многогранник среди нескольких картинок) — canDraw: false и объясни; текст аналога всё равно верни.
Шаг 6. ПЛАН КАЖДОГО ЧЕРТЕЖА — по техническим правилам ниже. Чертёж соответствует НОВОМУ заданию (новые числа/формулы), а не исходнику. Подписывай только то, что видно ученику на исходной картинке (имена точек, формулы, если они были подписаны). Не подсказывай ответ: искомое на чертеже-условии не показывается. Чертёж-вариант ответа показывает ровно то, что показывал соответствующий вариант исходника.

Верни ТОЛЬКО один JSON-объект без markdown-ограждений и текста вне JSON:
{
  "reasoning": string,          // кратко шаги 1–6
  "originalText": string,       // распознанное исходное задание (Markdown + $LaTeX$)
  "canDraw": boolean,           // можно ли построить ВСЕ чертежи
  "sceneType": "plane" | "line",// одна размерность для всех чертежей
  "task": {
    "type": "input" | "choice",
    "text": string,             // текст НОВОГО задания (Markdown + $LaTeX$), с метками [[figN]] для чертежей в тексте
    "answer": string,           // для "input": правильный ответ; для "choice": ""
    "options": [                // для "choice"; для "input": []
      { "text": string, "correct": boolean, "figure": "fig2" | null }   // figure — id чертежа в этом варианте; text может быть "" если вариант — только картинка
    ]
  },
  "figures": [                  // по порядку; id: "fig1", "fig2", …
    { "id": "fig1", "placement": "text" | "option", "drawPlan": string }   // drawPlan — формат плана из технических правил, переносы \n
  ]
}
Согласованность (проверь перед ответом): каждый figure с placement "text" упомянут меткой [[id]] в task.text; каждый figure с placement "option" указан ровно в одном варианте; других id нет. Все строки — в двойных кавычках; обратный слеш удваивай (\\frac).
