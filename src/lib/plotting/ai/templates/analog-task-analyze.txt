Шаг 1. РАСПОЗНАЙ задание: перепиши текст обычным текстом, формулы — LaTeX в одинарных долларах ($y = x^2$). Картинки исходника не пересказывай текстом — отметь, где они стоят. Результат — поле originalText.
Шаг 2. ПОЙМИ задание, сначала внимательно прочитав ВСЁ условие, затем сопоставив его с картинкой:
   — Отдели явно данные математические ограничения от того, что требуется найти. Выпиши в reasoning вид каждой функции, известные и неизвестные коэффициенты, роль отмеченных точек и искомое.
   — Формула в общем виде — это ОБЯЗАТЕЛЬНОЕ ограничение, а не отсутствие формулы. Например, f(x) = a*x^2 + b*x + c требует именно квадратичной функции (a ≠ 0), g(x) = k*x — именно прямой через начало координат. Восстанови коэффициенты исходника по видимым точным данным; при создании аналога выбери новые согласованные коэффициенты того же вида. В плане укажи явную функцию с конкретными коэффициентами. НЕ заменяй её гладкой кривой через точки, даже если коэффициенты в тексте не указаны числами. Неявное уравнение аналогично сохраняет свой заданный вид.
   — Построение по точкам допустимо только для графика, чей вид НЕ задан формулой или семейством функций в условии, и который нельзя надёжно восстановить точным уравнением. Координаты, прочитанные с сетки для определения коэффициентов, — данные анализа, а НЕ автоматическое указание рисовать дополнительные точки.
   — Составь в reasoning краткий список видимого: графики, явно нарисованные маркеры точек, подписи, пересечения с осями, положение характерных частей кривой и границы окна. Отдельно перечисли упомянутые в тексте, но НЕ показанные элементы. Упоминание точки в условии НЕ означает, что она отмечена или вообще попадает в окно.
Шаг 3. СОЗДАЙ АНАЛОГ. Смысл, тип и сложность задания НЕ меняются, ход решения тот же. Но изменения ОБЯЗАТЕЛЬНЫ: поменяй числа, коэффициенты, формулы, буквы или порядок вариантов так, чтобы задание стало новым и ответ изменился. Не будь чрезмерно креативен: не меняй тему, формулировку вопроса по существу, количество вариантов и тип ответа. Проверь, что у нового задания есть корректный однозначный ответ, и найди его.
Шаг 4. ФОРМАТ ОТВЕТА УЧЕНИКА: "input" — ввод ответа (число, выражение); "choice" — выбор из вариантов. Если в исходнике варианты — оставь "choice" с тем же числом вариантов.
Шаг 5. СКОЛЬКО ЧЕРТЕЖЕЙ и КУДА. Каждой картинке исходника, которую можно построить инструментом, соответствует один чертёж аналога.

   — Если картинки служат вариантами ответа (на каждой — свой вариант) — ставь их В ВАРИАНТЫ: placement "option" с номером варианта. Это предпочтительно, если задание подразумевает выбор картинки.
   — Иначе — в текст задания: placement "text"; в тексте задания поставь метку [[fig1]] (и т. д.) ровно там, где стоит картинка.
   — Если картинку построить инструментом нельзя (диаграмма, рисунок предмета, планиметрия без координат, многогранник среди нескольких картинок) — canDraw: false и объясни; текст аналога всё равно верни.
Шаг 6. ПЛАН КАЖДОГО ЧЕРТЕЖА — по техническим правилам ниже. Чертёж соответствует НОВОМУ заданию (новые числа/формулы), а не исходнику.
   — Сохрани визуальную роль КАЖДОГО элемента: то, что видно на исходнике, должно быть видно на аналоге; отсутствующие маркеры, подписи, координаты, вспомогательные линии и формулы НЕ добавляй. Видимые маркеры сохраняй даже без имени, но без выдуманных подписей. Вспомогательные вычисления не становятся объектами чертежа.
   — Различай сам график, видимое пересечение кривых, маркер точки и подпись точки. Они не взаимозаменяемы: пересечение может быть видно без маркера; упомянутая в тексте точка может быть за пределами окна. В «ПОСТРОИТЬ» включай отдельную точку только если её маркер был виден; в «ПОДПИСАТЬ» — только подписи, видимые в исходнике.
   — Сохрани, какие характерные части графика видимы и где они находятся относительно осей. Например, если вершина параболы ниже оси x, нельзя в аналоге переносить её на ось x, если это меняет изображённую конфигурацию задачи.
   — Если второе пересечение B в исходнике за пределами окна, в аналоге оно тоже ДОЛЖНО оставаться за пределами окна: не добавляй для B точку, подпись, координаты и не расширяй оси до него. Выбери новые коэффициенты и пределы совместно, чтобы видимые данные позволяли решить задачу, но скрытое пересечение не появлялось. Требование квадратного поля выполняй добавлением пустого пространства с другой стороны, а не раскрытием скрытого искомого.
   — Подписывай формулы только если они были подписаны на картинке, а не просто приведены в тексте. Чертёж-вариант ответа показывает ровно то, что показывал соответствующий вариант исходника.

Проверь форму кривой, положение вершины, пересечения и достаточность видимых данных для единственного ответа. Исправь аналог и планы, если хоть одна проверка не выполнена.

{
  "reasoning": string,          // кратко шаги 1–7, обязательные виды функций и проверка видимости

    "type": "input" | "choice",
    "text": string,             // текст НОВОГО задания (Markdown + $LaTeX$), с метками [[figN]] для чертежей в тексте
    "answer": string,           // для "input": правильный ответ; для "choice": ""
    "options": [                // для "choice"; для "input": []
      { "text": string, "correct": boolean, "figure": "fig2" | null }   // figure — id чертежа в этом варианте; text может быть "" если вариант — только картинка
    ]
  },
  "figures": [                  // по порядку; id: "fig1", "fig2", …

  ]
}
